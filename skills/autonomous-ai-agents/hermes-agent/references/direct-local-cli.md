# Direct local-model terminal clients

Use when the user wants `spark` / `heretic` shell commands independently of Hermes. Treat these as plain model chats unless an agent workflow is explicitly requested.

1. Inspect existing command names, the real interactive shell PATH, local inference endpoints and installed clients before creating anything. Reuse a mature native client; do not recreate an HTTP/SSE/REPL loop. Preserve the existing inference services and avoid loading duplicate model weights.
2. AIChat 0.30.0 was exercised with the installed Spark and Heretic services. Verify the installed version's official config/source before adapting it. Keep each launcher on its own `AICHAT_CONFIG_DIR` and `AICHAT_CONFIG_FILE`, pin its model selection, and exclude loopback from proxies. The scripts in `models/terminal/` are the deployment source.
3. For independent chat, do not import Hermes, contact its gateway, forward its system prompt, or load its memory/tools. The existing servers may still store their model files under the Hermes profile directory; that does not require a running Hermes agent.
4. `repl_prelude: session:temp` supplies in-process conversation context. `save: false`, `save_session: false`, `save_shell_history: false` and `function_calling: false` disable the corresponding defaults; `compress_threshold: 0` disables automatic summarization. Do not overwrite an existing AIChat profile or existing shell commands.
5. OpenAI-compatible client `patch.chat_completions.<model-regex>.body` can supply model-specific `max_tokens`, sampling and `chat_template_kwargs.enable_thinking`. Heretic uses thinking; Spark uses its fast mode. AIChat displays separate reasoning with `<think>` tags even in non-streaming mode. Validate final content separately from that documented client formatting; do not mislabel it as an inference failure or silently disable reasoning to make an exact-output smoke test pass.
6. Exercise both commands from a clean environment containing no `HERMES_*` variables. Test a real request, piped input, two interactive turns that require previous context, normal exit, missing configuration and an unavailable endpoint. Never stop a live service to simulate failure; use an isolated scratch HOME/config with an unused endpoint.
7. With a raw PTY, send Return as `process_manage(action='write', data='...\r')`. A submitted LF can insert a continuation line in Reedline instead of executing the prompt. Verify returned answers and the next prompt before sending the following turn.
8. Read back installed file bytes/permissions and resolve commands in the user's actual login shell. Check that no automatic message/session files appeared. Keep request/response fixtures and diagnostics in scratch, and publish only launchers, non-secret configs and restore documentation under the setup repository's authorized workflow.
